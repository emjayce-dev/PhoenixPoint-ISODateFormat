ISO Date Format
===============

A small quality-of-life mod for Phoenix Point.

Changes the Geoscape date display from:

DD.MM.YYYY

to:

YYYY-MM-DD

Example:

15.03.2047  ->  2047-03-15


Steam Workshop
--------------

The mod is also available through the Phoenix Point Steam Workshop.


Installation - Non-Steam
------------------------

Download the latest release from the GitHub Releases page.

The release contains the compiled ISODateFormat.dll and meta.json files
needed by Phoenix Point.

A compatible Phoenix Point mod loader/enabler is required for installations
that do not use Steam Workshop.


Source Code
-----------

The source code is included in this repository.

The project was created using the official Phoenix Point Workshop Tool and
targets .NET Framework 4.7.2.
